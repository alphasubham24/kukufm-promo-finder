This directory contains the complete, unedited outputs from executing our Promo Finder
solution on the official 50-episode input pack (Broken Soldier Duke), along with the 
rules-only baseline comparison and ground-truth evaluation benchmark results.

FOLDER STRUCTURE
----------------
1. 01_full_input_pack_llm_run/
   Contains the complete unedited outputs from the full 50-episode LLM pipeline run
   using AWS Bedrock (openai.gpt-oss-120b-1:0):
   
   • report.md
     Human-readable executive summary listing all 40 ranked promo clips with start/end
     timestamps, duration, opening hook lines, cliffhanger cutoffs, trope classification,
     composite scores, launch week posting plan, and quality audit.
     
   • promos.json
     Complete machine-readable JSON containing full metadata, segment cutpoints,
     and the line-by-line screenplay dialogue within every cut.
     
   • promos.csv
     Spreadsheet-friendly export with ranks, cut timestamps, hooks, cliffhangers,
     and editorial flags.
     
   • candidates_raw.json
     UNEDITED raw candidate proposals directly from the LLM before parsing validation,
     dead-air trimming, or snap-to-shot adjustments.
     
   • llm_responses.json
     RAW model responses for all 17 batch API calls, including token usage and reasoning.
     
   • quality.json
     Comprehensive audit log detailing validity rate (93%), rejected clips with reasons
     (e.g. length overshoot on Ep 34, 39, 47), and rules-vs-LLM disagreement flags.
     
   • dropped_duplicates.json
     Log of deduplicated promo candidates suppressed due to >50% IoU overlap with
     higher-ranked clips.

2. 02_baseline_rules_only_run/
   Contains the unedited outputs from running the deterministic rules-only pipeline
   (zero LLM calls) across all 50 episodes. This provides the exact baseline used to
   benchmark and compare the LLM's dramatic selection quality.

3. 03_evaluation_benchmark_results/
   Contains the evaluation metrics from benchmarking the tool's predictions against
   hand-labeled gold promos:
   
   • gold.json
     Ground-truth promo cut definitions labeled blindly without viewing model output.
     
   • evaluation_metrics.json
     Automated accuracy metrics generated by `python -m promo_finder.evaluate`:
     - Recall: 1.0 (100%)
     - Top-10 Precision: 1.0 (100%)
     - Mean start time error: 0.30 seconds (snaps cleanly to camera boundary)
     - Intersection over Union (IoU): 0.86 overlap with human editorial selection.
